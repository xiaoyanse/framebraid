# FrameBraid identity / 视觉标识

The selected identity is a **green FB monogram**. Media SDK and Vision SDK share this identity; component names remain explicit in text.

用户已选择 B：绿色 FB 字母，两个 SDK 共用品牌，组件名称在文字中区分。

- [Transparent logo](framebraid-logo.webp): square raster mark with alpha; use on a light background.
- [README banner](framebraid-banner.webp): ivory background, green logo and wordmark.

Generated using the built-in image generation tool, following imagegen/brandkit guidance. Delivered as lossless WebP for a small repository; decoded RGBA pixels were checked against generated PNG originals. The original PNGs are retained separately; the concept board and generation prompts are internally archived. These are raster assets, not hand-authored SVG masters or a trademark-clearance result.

使用内置文生图生成，无损 WebP 交付并核对解码像素与 PNG 原图一致。透明底已核实，原图另存。当前为位图，不冒充 SVG 源稿或商标排他性证明。

Visual direction: deep green, warm ivory and muted sage. Reference palette for documentation charts: green `#073F32`, ivory `#F8F6F0`, sage `#8BA28B`. Generated artwork may contain subtle tonal variation.

视觉方向为墨绿、暖米白与灰绿；图表使用上述参考色，生成位图不承诺每个像素都是单一色值。
