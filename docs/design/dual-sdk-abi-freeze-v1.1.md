# ABI 1.1 本地兼容扩展冻结依据

本地开发新增两个Media导出：显式解码设备初始化探测、已有context/decoder的UTF8 JSON快照查询。合同以dual-dll-abi.md §1.1扩展为准；旧结构、枚举、导出和所有权保持，旧1.0客户端仍可初始化新DLL。新客户端使用新增导出前须协商1.1；SDK包版本仍开发期，发布时另行定版。

历史1.0实施冻结正文保持原字节，先将freeze-v1.json原件复制到sdk/abi/history/freeze-v1-r5.json，新快照引用其SHA。freeze-v1.json文件名沿用“ABI主版本1”的当前指针，内容abiVersion=65537，不覆盖旧快照。仅更新当前头文件、常量及语言生成物；布局没有变化。冻结只表示本地合同受控，运行验收和正式发布另记。

未承诺：RTSP源策略与完整源快照、其他平台/硬件矩阵、硬件推理自动选择、4h/24h。无需新增通用框架或改宿主，禁止通过保留字段偷偷扩展。
