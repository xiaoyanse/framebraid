通过既有C异步图片入口，实际PNG解码、模型前处理、ORT Run与Pose后处理，单在途/batch1/5 FPS。三个热身后，每轮20请求/4秒，三轮与一轮观察关闭控制。资源包含Python验证/输出复制/归还、SDK、运行库和采样；响应是submit→fetch返回，不能称纯ORT延迟。不同加速请求用独立进程，遵守单加速域。
