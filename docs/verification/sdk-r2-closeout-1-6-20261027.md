## 三、整包结论（MET-2 口径）

1. **同路径优化全部有量化与正确性对拍**：转换缓存、采样前移、张量直写、最近邻缩放、RG 表（-23%）各自由实测支持，输出正确性以逐字节/位级对拍或穷举保证。
2. **跨后端取舍如实保留负结论**：本机（Intel Arc 140T + RTX 5060，CPU RGBA 回读合同）硬解单路/双路均未体现 CPU 卸载；该结论限定当前交付合同与设备，不构成对硬解路径的否定，GPU 原生输出/多路现场收益未验。
3. **保护指标全程有效**：帧龄预算、有效交付率、提交节拍、输出像素一致性（诊断级）、池/队列/关闭语义在全部测量中作为硬门。
4. **未验项不冒充**：真实网络抖动矩阵、多路（>2）并发、GPU 引擎/显存细粒度归因（观察器为引擎单项采样）、跨进程共享帧、现场码流——均如实登记。
