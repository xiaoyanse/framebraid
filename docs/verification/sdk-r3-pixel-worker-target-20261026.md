# R3像素执行隔离测前卡

基线`1eb75d5`，仅本地SDK；与R2真实采样低交付分开，不改max_fps语义。

- 主目标：读流线程不执行原生像素工作，受控阻塞时健康压缩交付继续；每活动worker先占现有decoder槽，不以替代线程回避阻塞。
- 有界性：内部像素队列服从既有压缩队列策略和总字节，最多队列上限+一项在途；元数据提前计费，共享包按实际拥有者计费，溢出清参考链等待关键帧。关闭不提前释放原生在读资源。
- 确定性测试：阻塞像素处理器期间至少100项压缩任务仍完成；像素队列不超限，过载丢弃可对账；解除阻塞后只从新epoch的随机访问点交付，无旧配置帧、预算或线程残留。至少100轮小型启动/停止可在后续1.4整合，不能只测一轮称全覆盖。
- 实际运行：新Release DLL的H264/H265/MJPEG回环，参数切换、软件/硬件及纯压缩路径；沿用MET-2 S2的5/10/30与混合消费者窗口复核交付/帧龄，30配置不足继续登记，不能少交付换低CPU。
- 本小包不关闭全部故障矩阵和4h/24h长跑；实际驱动永久挂死不承诺进程内强杀。源码/工具/运行库/输入和DLL指纹及原始失败保存到`.local/evidence`，临时服务结束后回收。
