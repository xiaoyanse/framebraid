- 主目标：同源1080p30/GOP30/B帧下，修复略早到期帧被丢造成的约16～17FPS交付，30上限三轮达到原S2的24FPS调查线；5/10及混合至少4/8/24FPS（固定4s窗口对应16/32/96帧）。不把调查线改成稳定FPS保证，不放宽已有最短间隔。

- 定向：纳秒边界、FPS=0及极值、无回调/停止/重置、提前查询不耗机会、停止打断等待与epoch/配置失效；虚拟30FPS转换数量与像素指纹对拍；实际RTSP/真实硬件及参数变化回归。HEVC/MJPEG和动态尺寸矩阵若未补齐，R2 1.2仍不整项勾选。
