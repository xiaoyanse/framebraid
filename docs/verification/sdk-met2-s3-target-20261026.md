# MET-2 H5 / S3 CPU代表模型测前目标卡

状态：测前固定。依据[MET-2](../PERFORMANCE_ACCEPTANCE.md)与[H5任务](../../openspec/changes/sdk-r5-inference-scheduling/tasks.md)。本包主目标是**证明目标模型实际执行、既有strict/CPU回退正确，并形成带资源分母的CPU A/A**，不要求加速后端更快，不实施新的模型选择ABI。

| 项目 | 约定 |
| --- | --- |
| 身份 | 当前Vision DLL实际notes/SHA为准，工具源码与目标卡摘要归档；本仓固定Pose档案 `pose-yolo26-e2e-coco17-v1`，模型SHA `80fb5f58a3f6ec18909427ecc74fec0910196c2d2e924659eaae6dea5857b957`；从宿主已有公开模型文件只读复制到SDK私有测试目录，不修改宿主 |
| 输入 | S1自产testsrc2首帧PNG，1920×1080，摘要固定；经过真实SDK图片解码/letterbox/Pose前处理、ORT执行与后处理，不把合成Identity当代表模型；无真实人员标注，不验业务召回率 |
| 运行库 | 已有CPU ORT明确目录，固定DLL摘要；不能在一个进程切另一ORT包，不安装系统依赖或调用现场；CUDA/OpenVINO缺EP时应strict拒绝，允许CPU回退则实际Run成功 |
| 调用 | 每个进程只持一个模型；2个模型内线程、总预算16、2个域slot；单在途、batch1，5FPS，先3个热身，再每轮20请求/4秒，CPU同一模型3轮；2个加速请求各strict/允许CPU回退在独立进程，避免加速域污染；最多8个子进程/3分钟 |
| 时间 | 单列context初始化/模型加载冷启动；稳态submit→结果可取含前处理、SDK排队、Run/后处理与Python轮询，不称纯ORT耗时；SDK起止毫秒字段只按整数毫秒报告，不据其差值捏造细段 |
| 保护线 | 本次实验响应≤500ms、每轮20请求最终全归还且无重复/错关联、0拒绝/取消/失败、线程峰值≤16；若不能满足5FPS则如实报节拍迟到与延长窗口，不静默下调FPS。数值是实验线，不是SDK通用SLA |
| 输出与所有权 | 验实际backend、帧/请求/模型身份、raw tensor形状/有限数值与同CPU重复输出摘要；输出复制/校验/ack/release成本计进程CPU，但不计结果可取延迟；无真实模型精度/跨硬件数值容差承诺 |
| 资源/重复性 | 复用S1进程CPU/GPU有界采样，GPU缺实例为未知；3轮全保留，报告CPU/延迟绝对及相对跨度。调查门CPU 0.1 CPU-s/4秒且10%、响应2ms且10%，并须超A/A跨度；本包不改推理路径，不作新旧提速结论 |
| 证据 | `.local/evidence/met2-s3-20261026-*`，模型/输入只在`.local/tests/met2-s3`；所有进程有超时，失败记录保留，不发布模型/输入/运行库 |

首轮功能短烟测不并入三轮；无法跑加速EP如实留未验。CPU真实Run与缺EP回退不能关闭H5.1～H5.4完整设备/模型/恢复矩阵，也不能替代R4五类精度与长跑。
