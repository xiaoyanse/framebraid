# R2 1.3 前处理直写张量测前目标卡

测前基线`ddae515`，SDK main串行。依[MET-2](../PERFORMANCE_ACCEPTANCE.md)及[R2任务](../../openspec/changes/sdk-r2-frame-hot-path/tasks.md)，内部优化、不改变公开ABI/API、像素算法、模型选择或输入寿命。

- 主目标：消除`prepare`先分配`Vec<f32>`再复制到`TensorData`的完整临时缓冲；640×640×3×4应至少减少一次4,915,200字节分配与等量复制，Rust分配计数在独立原语中采集，不把分配请求字节当峰值/RSS。
- 次目标：记录同路径局部prepare时间是否改善；不存在新旧系统吞吐/全程零拷贝承诺。优先机制正确，不为耗时噪声牺牲结果或预算。
- 原语场景：沿用现有1920×1080 RGBA→640×640 letterbox/NCHW/f32基准；输入/参数/线程/编译profile固定，20次热身、每轮200样本，改前同实现3轮，改后3轮，再使用两份保存的Release原语交替3对，每对100样本/20热身；最多12次负载/3分钟实测。计时排除输入生成、哈希与输出析构，不对比CPU/GPU。
- 对照：保存改前EXE与`prepare.rs`原字节/摘要；输出完整字节FNV与变换逐项保持。保留旧比较器5%标签，但判断结合A/A绝对波动；局部P95调查门0.2ms且5%，同时必须超同实现跨度，不作为自动通过线。
- 正确性：旧算法作为仅测试编译的冻结参考，RGBA/RGB/BGR、NV12三色矩阵/两范围、带行填充、letterbox/stretch/crop、NHWC/NCHW、RGB/BGR顺序、三类归一化及自定义均值方差交叉对拍；小尺寸、奇数目标、上下/左右补边、预算不足/坏参数均保留错误键。完整输出及坐标变换按原值，不使用宽松像素误差代替。
- 拥有者：仍由当前`TensorData`的u64对齐自有存储持有；长度/预算验证发生分配前，不能依赖可被修改的公开dtype/shape盲目转f32，也不复用其他请求的活缓冲。新方法仅内部可见；生产路径无跨请求全局可写缓存。
- 真实链：复用S3固定Pose模型/输入与CPU ORT，当前Vision DLL候选重建后至少做定向图片/异步归还与同输入输出摘要对照；模型阈值/坐标不变。源码/制品身份和核心修订覆盖清单同步，不改历史提取指纹。
- 非本包收口：R2-SAMPLE-01/02、真实加速/恢复、多路承载、4h/24h、跨语言/shared-frame其他复制及SIMD不被关闭。输出位相同和少一块分配只证明限定机制，不冒充整体CPU节省比例。
- 证据：新`.local/evidence/r2-prepare-direct-20261026-*`；旧EXE/冻结参考归私有测试与仅测试模块，模型/运行库不提交。停止条件为字节/变换不符、分配未减少、预算/所有权/关闭失败；失败原始轮不删除。
