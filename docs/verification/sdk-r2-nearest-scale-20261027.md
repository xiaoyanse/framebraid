# R2 最近邻缩放局部优化（2026-10-27）

基线为 `8393ddd`。最近邻分支将同一像素的坐标计算和逐通道浮点转换改为一次坐标计算与按通道复制；双线性保持原插值顺序，未引入 SIMD、共享缓存或额外堆分配。输入尺寸及长度校验、输出拥有权和预算不变。

目标卡和原始数据位于 `.local/evidence/r2-resize-20261027/`。预分配的合成 RGBA 缓冲，1920×1080→640×360，预热后每轮10次，同进程交替3轮：旧版最近邻 15.298～15.733 ms/10次，新版 6.524～6.648 ms/10次；旧/旧 A/A 为 15.113～16.612 ms/10次。双线性旧版 42.188～43.384、新版 40.986～45.108 ms/10次，本次不声称双线性改善。另一次曾观察明显负载波动；有其他项目编译并发，结论仅针对本机这一局部样本，不等于实时吞吐、整机 CPU 或 GPU 卸载改善。

最近邻与原半像素公式逐字节对拍 12,096 组输入/输出尺寸及1～4通道；受影响包测试 am-camera 67 通过/4 忽略、am-camera-ffi 84 通过/11 忽略，NAL 2 通过；严格 clippy 和 Release 构建通过。真实 DLL 的合成 H.264/H.265、四种像素格式、两种缩放、持有/释放与预算路径通过；原始测试报告已归档。首次使用错误样本目录导致文件不存在，指定已有隔离样本后重跑成功。此项不代表共享帧搬运、SIMD、跨语言性能或 R2 全部完成。
