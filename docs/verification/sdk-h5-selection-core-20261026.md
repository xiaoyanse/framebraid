# H5.0a 推理选择核心阶段验证

2026-10-26，评审基线 `83fcaebcb350eae750ea9ba045ba4eb06efe9459`。SDK main本地阶段保存，不修改AM-RT，不发布，不表示H5整包完成。

## 已接线与验证边界

- Rust `Model::load_selected`接受1～3个有序后端/设备候选，严格模式只试首项；允许回退也不能补入未允许的CPU。旧load/C模型入口继续旧requested/strict规则，无新增C导出、枚举或布局。
- CUDA从系统驱动显式探测，最多16设备、单轮准入、软预算；枚举ordinal独立于视频DXGI索引。本机真实枚举RTX 5060 Laptop GPU，最终一轮48ms；不等于CUDA ORT执行成功，不把设备UUID写入公开记录。
- provider编译支持、注册、目标模型Session和原生Run分开。禁继承环境默认EP，避免CPU请求暗中走GPU；保留独立且受既有线程预算约束的会话池。模型报告不复制原生路径/消息；ORT自身logger不在本阶段改写。
- 全局后端锁不跨原生模型创建；部分provider装载失败仍保守保留单加速域，同域重试/CPU允许，不缓存失败为永久不可用。模型的私有选择快照用于执行记账，可修改的旧公开字段不能伪造GPU已执行。
- 候选选择预算不含预先文件读取和之后I/O核验，原生调用不可强杀；成功但超软预算明确报告。运行期失败不自动重放输入、不即时迁移模型。
