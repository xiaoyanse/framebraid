**结论（同负载、同输入、真实模型）**：
- **CUDA 同步推理 P50 约 26.7～28.6ms vs CPU 约 97～116ms——3.6～4.2 倍加速**；CUDA P95 波动远小于 CPU（30～41ms vs 115～337ms），尾延迟更稳。
- CUDA 侧代价：首次会话加载约 0.5～1.4s（含 EP 初始化与 CUDA 上下文），比 CPU（约 0.18s）高；进程内会话复用时该项摊薄。
- 各轮 max 的偶发尖刺（1.1～11.3s）为进程冷启动首帧（子进程隔离设计所致），不影响 P50/P95 结论。

**输出对拍：字节指纹不同，但结构化语义对拍通过（深度对拍已完成）**。首 64 字节指纹不同（EP 数值差异预期）；随后按 R4 真实图口径（bus.jpg，`c02019c4…`，本图 4 有效检出行）做深度对拍：CPU 与 CUDA 各 4 行，**有效行 row 序一致 4/4，置信度最大差 0.00012，坐标最大差 0.04px**——数值容差内语义一致（工具 `.local/evidence/gpu-m1-met2-20261028/pose-parity.py`，数据 `pose-parity.json`）。前述 met2-s3 input.png 在本路径置信度全低于阈值（0 有效行），不适用有效行对拍，如实说明。

**边界**：单图单模型同步路径；不含异步/批量路径 GPU 对照（后续 M2 阶段随 GPU 帧管线一并）；样本 20/轮为快速对照，非严格 MET-2 目标卡三轮全量（目标卡合格判据 20/20 成功已满足）；GPU 引擎占用未观测。CUDA 加速结论限定本机 RTX 5060 + 该 Pose 模型 + 同步单帧路径。
