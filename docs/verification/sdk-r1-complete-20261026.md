# R1 性能基线阶段验收（2026-10-26）

结论：**R1 的 CPU/合成最小基线与有界测量工具完成**，可作为 R2/R5 优化前证据。
这不是 R1～R5 全部完成，不是硬件、YOLO精度或生产长跑验收。此前
[工具检查点](sdk-r1-baseline-20261026.md)保留，未完成项由本记录补充关闭。

最终材料在 `.local/evidence/r1-{prepare,decode,capture,inference}-final-20261026`，
共27份逐负载报告；`.local/evidence/r1-observation-baseline-20261026/observation.json` 保存观测开销。
之前探索/中途失败目录不当最终结果，原字节保留并不改写。

| 项目 | 三轮观察 |
| --- | --- |
| prepare平均/P95(ms) | 平均7.611/8.152/8.139；P95 9.013/9.942/10.612；每次5分配/9,830,454请求字节，摘要始终`ddf89c9aea3b3f3b` |
| RGBA转换平均/P95(ms) | 平均2.678/1.893/2.387；P95 4.940/2.471/4.460；每轮220创建/220释放，摘要`8816365bfed01b95` |
| 推理单请求/预算内 | 每轮32/128均交付，帧ID/源ID/完整输出正确；无遗留外持，SDK线程peak≤16 |
| 推理超预算慢消费 | 每轮1024次尝试，交付+拒绝守恒，含20ms消费等待；拒绝比例受生产/执行竞争影响，不能挑较少交付的一轮声称更快 |
| 抓图单请求/预算内/过载 | 每轮16/32全交付；过载256尝试=64交付+192明确拒绝，单个请求ID匹配，图片字节完全一致，收尾队列和外持均为0 |
| 本轮时间预算 | 27份最终报告均无局部/结果龄预算越界；不是业务SLA或长跑保证 |
| 进程私有内存变化 | 推理各负载最大增长12,288B；抓图最大155,648B，均低于调查线；短测不能证明无泄漏 |

观察开销：Rust局部空计时平均约24～29ns；Python空计时平均约36～40ns；
加载空闲模型的实际DLL stats查询+释放均值1.329/1.418/1.413μs。
实际负载下额外stats开启/关闭各做三轮，P95范围约0.98～1.43ms与1.16～1.19ms，
轮询/调度噪声占主导，不能由此推导负开销或固定开销百分比；直接stats微基准另列，
不从生产时长里盲减。摘要在计时区外，分配计数在单独调用采集；Sws包装计数仅用于局部对照。

重复波动明显：最终prepare均值范围约7.61～8.15ms，转换约1.89～2.68ms，
采集单请求P95约10.84～25.58ms；因此后续必须同机同负载、机制计数与三轮尾延迟联合评估，
小于这些噪声的差异不认定提速。各业务负载样本不足1000，P99只观察，不作可靠尾分布承诺。
