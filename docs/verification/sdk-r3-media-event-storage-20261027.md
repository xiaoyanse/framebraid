# R3：媒体源事件固定存储与停止回收

## 边界及改前证据

评审基线`5820e73bb094e62f2fd7537e8b09c055bc410556`，对应R3 1.1g。仅SDK内部预算和事件回收，不改AM-RT、C ABI、视频采样或硬件策略，不发布。MET-2 M-RECOVER/S5主目标为存储先准入、空闲容量持续计费、忙回调不被覆盖且排空后真正释放；保护已有丢旧提示策略、正确视频、线程复用与关闭屏障。

旧实现只计活Event，VecDeque自行扩容；停止时clear仍保留容量。改前定向测试实际得到停止后capacity=4、预期0而失败；按本机Event=72字节推算288字节槽存储，不含allocator开销。此证据不代表进程RSS测量，也不把旧逻辑项数上限当完整存储计费。

## 实现与量化结果

注册时依据当前Context控制项/字节、已有占用和64项硬限计算槽数；先占一个存储控制项及完整槽字节，再try_reserve_exact。活Event另占控制项，不重复计预付槽字节；排队+忙项不超槽数、push不扩容。未注册不分配，注销/停止待忙回调结束后销毁Vec再归还许可。准备/工作句柄锁/线程创建失败不留存储或新线程。

| 定向场景 | 结果 |
| --- | --- |
| 71字节，尚无存储 | 分配前resourceExhausted，容量和控制占用0 |
| 72字节、一槽，连续100个提示 | 容量始终1、控制字节72；存储+活项共2项，保留最新提示，旧提示丢弃99次、无扩容 |
| 一个忙项加一个待处理项，第三个提示到来 | 仅替换待处理旧提示，忙项身份不变，丢弃计数1 |
| 仅一个忙项占满一槽 | 丢弃新提示、计数1，不释放或覆盖忙项 |
| 忙回调期间停止 | 清待处理项但保留存储及忙项；忙项返回后容量/项/字节归零 |
| 单控制项注册/百次正常注册注销 | 额度不足拒绝且没有worker；正常100轮复用同一实际ThreadId，每轮注销后存储归零，最终停止join后无worker |

存储预付可能比稀疏通知时的旧小队列占用更多预算；收益是可预测的容量、运行期无队列扩容和退出回收，不能据此宣称RSS普遍下降。注销允许保留原有单条空闲事件线程，Source停止/关闭才join；未新增每事件线程或原生后台服务。

5项新单测、Source既有6项（含真实源对象回调注销等待/阻塞重入拒绝）及Media FFI默认并行全组38项通过、11项需显式原生材料ignored。不将ignored计入通过，也不将空Weak源的队列单测当作真实相机验收。

## 真实Release回环保护回归

沿用合成H.264 256×144/10 FPS、随机回环端口、同源多消费者；同时阻塞事件和帧回调、停读编码订阅。预设门槛仍为健康新鲜FPS≥7.5、接收帧龄/交付间隔≤750 ms、聚合队列≤50项/12 MiB、无额外重连，停止后零具名媒体worker及数据队列/外持。

| 轮次/阶段窗口 | 正常/压力/恢复新鲜FPS | 压力帧龄最大 | 压力交付间隔最大 |
| --- | --- | --- | --- |
| 首轮，各2秒 | 8.96 / 8.97 / 9.00 | 52 ms | 137.82 ms |
| 复核B，各4秒 | 9.48 / 9.34 / 9.80 | 49 ms | 152.13 ms |
| 复核C，各4秒 | 9.49 / 9.58 / 9.60 | 50 ms | 153.97 ms |

三轮均通过，压力数据队列峰值分别9/466,432、7/458,547、7/458,547项/字节，无重连，慢编码消费者按关键帧恢复，注销后无迟到回调，停止后无具名媒体worker。队列峰值是原数据通道统计，不冒充本包控制存储或进程RSS。

首轮两秒窗口比历史少约一帧，原始慢轮保留；在新增followup-target卡中预先限定再跑两轮四秒窗口，未反复重测凑绿。后两轮是保护复核，不与历史短轮混算提速；本包不声称整体吞吐改善或严格满标称FPS。
