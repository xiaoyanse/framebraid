# R2 H2.4 尺寸/profile 矩阵与关键帧重同步定向验证（2026-10-27）

源码基线 `main` 提交 `722b84a`（本批只新增测试脚本与样本，无 SDK 源码修改）。DLL 使用 `.local/build/current/release` 现有开发构建（Media SHA-256 `0887f856fcc6b77bc2e2d54184aa1e7f9760b05306327ff326c71ba99f927fa5`，非干净发布候选），FFmpeg 运行库 `.local/runtimes/ffmpeg-h2-20261026/runtime`（含 d3d11va2 配置）。本机 Intel Arc 140T + NVIDIA RTX 5060 Laptop，实际选中 NVIDIA D3D11VA；不连接相机或现场设备。

## 场景与结果

脚本 `scripts/sdk/test-decoder-h24-matrix.py`，样本 `.local/tests/h24-matrix-20261027-v6`（指纹见 `.local/evidence/h24-matrix-20261027-samples.json`），结果 `.local/evidence/h24-matrix-20261027-result.json`。每样本双策略（PREFER_HW/SOFTWARE_ONLY）各解码一次：

| 样本 | profile（ffprobe 实测） | 尺寸 | PREFER_HW 实际后端 | SOFTWARE 实际后端 |
| --- | --- | --- | --- | --- |
| h264-360p-main | Main | 640×360 | ffmpeg-d3d11va（硬件） | ffmpeg-cpu |
| h264-720p-main | Main | 1280×720 | ffmpeg-d3d11va | ffmpeg-cpu |
| h264-720p-baseline | Constrained Baseline | 1280×720 | ffmpeg-d3d11va | ffmpeg-cpu |
| h264-1080p-high | High | 1920×1080 | ffmpeg-d3d11va | ffmpeg-cpu |
| h264-1440p-high | High | 2560×1440 | ffmpeg-d3d11va | ffmpeg-cpu |
| h265-720p-main | Main | 1280×720 | ffmpeg-d3d11va | ffmpeg-cpu |
| h265-1440p-main | Main | 2560×1440 | ffmpeg-d3d11va | ffmpeg-cpu |
| h265-2160p-main10 | Main 10（10bit） | 3840×2160 | ffmpeg-d3d11va | ffmpeg-cpu |

全部 8 项 PREFER_HW 一次硬件成功（`source_generation=1`，无恢复路径），输出尺寸校验通过；SOFTWARE_ONLY 全部 CPU 且非硬件。生成器在每样本生成后用 ffprobe 断言真实 profile，杜绝参数声称与实际不符（开发中实证两类陷阱：ffmpeg wrapper 的 `-profile:v` 被编码器 params 解析覆盖、x265 `keyint=1` 静默升 Rext——首轮样本实际为 Rext，被硬件拒绝后正确回退 CPU 且保留恢复代次，该行为与既有 frame.h265 Rext 用例一致，最终矩阵样本全部修正为声明 profile）。

**关键帧重同步**：30 帧 H.264 GOP（IDR@0/12/24，含 B 帧）丢弃前缀 538,354 字节（帧 0–11），从第二个 IDR 起按 AU 逐包提交 18 个访问单元：PREFER_HW 与 SOFTWARE_ONLY 均精确解出 18 帧、尺寸一致——非随机访问点前缀被抑制，硬解与软件在随机访问点重同步行为一致。

## 覆盖边界

单 AU 矩阵 + 一次重同步场景，实际后端以解码器报告为准，不含吞吐验收；[S1 单路资源对照](sdk-r2-current-s1-20261027.md)仍是最新的 MET-2 CPU 卸载数据，本矩阵不新增资源结论。运行期失效恢复（Rext 拒绝/回读故障注入→CPU 恢复）沿用 ABI 1.1 与 H2.3a 既有证据；关闭竞争由共享池 1.5b 与 R3 media-workers 记录覆盖。多路并发、长跑与现场码流未验不冒充。H2.4 父项按本子项加既有证据评估，多场景 MET-2 资源矩阵仍开放。
