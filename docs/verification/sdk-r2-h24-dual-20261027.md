**结论（限定）**：同进程双上下文双路 1080p30、CPU RGBA 回读交付合同下，硬件路径（DXVA2）全进程 CPU 时间高于软件路径，未体现 CPU 卸载，方向与 [S1 单路](sdk-r2-current-s1-20261027.md)一致；两策略组均达成 2 合格路、节拍完整。不外推更多路数、现场码流、GPU 原生输出或其他交付合同；观察器开销未单独对照。
