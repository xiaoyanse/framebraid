# R2 H2.4 四路解码资源对照（2026-10-28）

同 [双路对照](sdk-r2-h24-dual-20261027.md) 方法学（同流 `ebe30675…`、预热 2s/窗口 6s/每组 3 轮、帧数守恒），脚本参数化为 4 路（`benchmark-decode-dual.py --lanes 4`），DLL 同 r5clean 候选构建链（提交 `898ff64`）。目的：探测硬解 CPU 承载是否随并发路数显现卸载趋势。

| 组（四路同策略） | 三轮全进程 CPU-s | 合格路 | 每路有效 FPS |
| --- | --- | --- | --- |
| cpu×4 | 3.203 / 3.125 / 3.031 | 4/4 | 29.9 全部 |
| hardware×4（实选 ffmpeg-dxva2） | 4.203 / 4.297 / 4.125 | 4/4 | 27.9（r1 一路）/ 29.9 / 30.0 |

CPU 组随路数近线性（双路约 1.6 → 四路约 3.1 CPU-s）；硬件组 CPU 时间持续高于软件约 30%，**差距比例与单路/双路一致，卸载趋势未随并发路数显现**——在 CPU RGBA 回读交付合同与本机设备（D3D11VA/DXVA2）条件下，1/2/4 路负结论一致。r1 硬件组一路 27.9 FPS 为首轮抖动（仍达合格线）。不外推 GPU 原生输出、其他适配器或现场码流；组间差（约 1.1 CPU-s）大于组内波动（≤0.2），方向可信。
