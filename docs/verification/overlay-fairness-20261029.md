# 叠层队列公平性验证（2026-10-29）

在原 36 项/8 MiB 总预算内为最新 overlay 预留 1 项和 512 KiB（对齐宿主 MONITOR_META_BYTES）；视频及控制项合计最多 35 项、视频载荷最多 7.5 MiB。单个视频包超 7.5 MiB 按既有超大包终态处理；超过 512 KiB 的 overlay 拒绝，保留之前合法值。此取舍减少可用视频队列容量，不改变 H.264 包的相对次序。配置/重同步先于叠层，关闭、配置和重同步清除旧叠层；持续叠层与视频交替取出。

本机 fanout 定向 14 项通过：满视频队列最新叠层、连续叠层与视频公平、512 KiB 可发送和超限拒绝、代次/重同步/关闭清理、预算和慢客户端；无真实相机或现场验收。
