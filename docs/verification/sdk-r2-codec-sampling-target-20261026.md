# R2采样编码补充测前卡

基线`2d44efa`，生产路径不改；只扩展观察器与显式环境测试。沿用MET-2/R2节拍目标，不再重复H.264三组A/B。

- 固定上阶段Release及FFmpeg，合成1080p30 HEVC Main（GOP30/B帧）、MJPEG yuvj420p；离线备料后ffprobe核编码/尺寸/像素格式/标称帧率并保存指纹。
- 真实回环RTSP每编码一组纯压缩、5/10/30/混合，2s预热/4s窗口；最低16/32/96帧、压缩至少27包/s、接收→消费P95≤250ms为调查与保护线。不足如实留证，不以改尺寸/改阈值称原场景通过，不承诺标称FPS。
- 原始逐帧PTS/身份及关闭归还检查不变。计数器初始化后有界排空预热队列。无新增CPU收益或新旧A/B承诺；CPU波动及不能观测的字段保留。
- 实际worker/原生库/真实时钟：H.264/HEVC/MJPEG，5/10/30/30消费者，交替25/42ms输入；256×144→128×96配置切换，核PTS、配置/维度、严格选择间隔与关闭额度。合成独立随机访问画面仅验证机制，不冒充真实GOP吞吐。
- CPU必测；本补充不关闭硬件/profile/位深/故障整矩阵，也不替代R2 1.5或R3/R5的4h/24h长跑。源输入不足、JPEG高负载等若使保护线失败，保留该失败后再决定实现修复，不靠缩小范围勾选整包。
