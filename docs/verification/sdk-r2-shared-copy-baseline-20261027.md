# R2 共享帧搬运局部基线（2026-10-27）

源码内容对应 `9614dbe`；Media DLL 在提交前由未提交源码构建，构建身份为 dirty，Vision DLL 于提交后构建，因此该测量并非干净候选包验收。使用本机 Release Media/Vision DLL；Windows x64、同进程合成 1920×1080 RGBA，单槽、单生产者、单消费者，每帧 8,294,400 字节。预热10次，记录60次，连续三轮；使用 Python ctypes，分别计时调用共享池发布、借用、`ctypes.string_at` 生成 Python bytes、归还。每次检查首末字节和长度；源/目标内容使用合成数据，不接相机、不运行推理。发布为SDK将外部像素复制入共享池，借用为只读映射的租约，不意味着生产链零拷贝；string_at 是调用方主动复制，与只读借用交付合同不同。

| 操作 | 三轮 P50（微秒） | 三轮 P95（微秒） |
| --- | --- | --- |
| 发布 | 1032.2 / 1168.6 / 1198.2 | 2253.2 / 2596.4 / 2285.2 |
| 借用 | 22.9 / 22.4 / 21.9 | 39.7 / 37.5 / 38.6 |
| Python 显式复制 | 3791.8 / 3314.4 / 2534.7 | 7576.3 / 6401.1 / 4010.1 |
| 归还 | 25.2 / 25.4 / 21.5 | 34.9 / 46.1 / 60.3 |

调用成本包含 Python/ctypes/SDK与内存分配，不能归因于单一部分；三轮存在明显波动，不比较为端到端延迟，也不推断跨进程或 C#。分别统计的操作不组成同一可替代合同的速度对比；禁用复制只适用于能安全持有租约的调用方。首次试运行因为合成帧关联元数据无效返回 invalidArgument，设置有效元数据后运行成功，未修改 SDK 源码。

测试脚本及每次原始记录位于 `.local/evidence/r2-resize-20261027/shared-bench.py` 和 `shared-measure-{1,2,3}.json`。本次仅建立局部量化，不关闭 R2 1.4：真实源、跨进程/C#、缩放链组合、缓冲复用与 SIMD 是否有收益仍需按需评估，安全持有/关闭与资源定向验证不得由本基线替代。
