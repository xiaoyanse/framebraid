## 存储与生命周期

句柄与外持Buffer登记各沿用每库4096项上限，索引首次使用时try_reserve_exact固定连续槽，按地址排序二分查询，不再由HashMap桶倍增隐含存储。先预留再登记；首次分配失败返回resourceExhausted且不发布，已有项不替换、随后可重试。空闲容量直到域卸载才释放，不将暂时清空伪装成已经退账。

销毁隔离区保持4096个Box token，先淘汰最老项再入队，避免短暂第4097项导致8192容量；destroy后使用仍为UB，未满隔离区不提前释放地址。级联关闭使用32项强引用栈块，按地址游标访问，释放注册锁后通知；被快照持有的子项销毁返回tryAgain并恢复登记，快照退出后可成功。没有强杀在途工作或提前归还外持引用。

Windows x64基础索引：句柄65536字节、Buffer131072字节、隔离区引用槽32768字节，均为每库而非每Context；三者合计229376字节。前两项在各自首次登记分配，隔离区槽随首次句柄登记准备。Entry本体112字节，Arc头、token内容、服务体/错误字符串和allocator另计，不能把索引合计称为进程RSS或全部SDK存储。基础索引与Context载荷额度分列，不提高公开上限。
