# Design: SDK B1 — 执行错峰与账目精估

> **B1.1 已定稿（2026-11-12 取证回填）**：口径溯源结论改变设计重心——
> 挤兑是 **CPU 像素通道**现象（24B/px=合并缓冲 12B+ORT 副本 12B 真实并存，
> 无收敛空间）；**GPU 帧直传路径 exec=0**（设备侧组装零 host 驻留，
> input.rs:196/250-276、pipeline.rs:158-165 零 CPU 回读），双 Model 批 4
> 现行账目 8×12B/px×640²=37.5MiB<64 **已经解锁**（评估实验走 pixel 通道
> ——multilane-scheduler.rs:477 AM_IMG_PIXEL_VIEW 实证）。B1 修订为：
> 错峰=CPU 像素通道的唯一路径（算术自核通过）；GPU 直传通道现状文档化
> （B1.7/α'）+B1.6 补 GPU 直传验证臂。

## 1. 现状账目模型（批 E 语义，2026-11-12 实测校准）

- 挂起份额（窗口期）：CPU 帧拷贝平面/编码载荷；GPU 帧接受段设备张量；
  张量自有副本——1080p→640 实测 ≈3.1MB/项。
- 执行份额（执行开始补账）：合并缓冲+ORT 输入副本 24B/px 口径——实测
  校准 ≈9.8MB/项（640² 输入），执行完成/取消/TTL/排空全量归还。
- ctx 总量 64MiB，class/context/executor 三层，满照拒。

## 2. 挤兑机理（评估实验归因）

双 Model 同参窗口（同 w40）天然同相：同时凑满→同时执行→执行份额同时
入账叠加。批 3 双 Model 峰值 2×(9.3+29.4)=77.4MB>64、批 4 2×(12.4+39.2)
=103MB——提交层整笔拒绝（实测 75% 拒绝率）。

## 3. 执行错峰（主策略）

- **执行槽**：ctx 级互斥量，语义="执行期份额入账窗口"。**持槽窗口=补账前
  取槽至执行完成（账目归还）释放**（B1.2 实现定稿，较本节初稿"补账完成即
  释放"加长——若补账即释放，下一 Model 补账时先执行方份额仍在账，批 3/4
  照旧拒绝；峰值算术只在"任一时刻至多一个 Model 处于执行态"下成立）。
  其余 Model 排出的批在挂起份额下等槽（挂起账目立即入、执行补账延迟）。
  GPU 直传批（exec=0）不持槽（exec_stage.rs:54-56 全零批旁路）。
- 峰值账目=单 Model 执行份额+全部挂起份额：批 3=29.4+18.6=48MB、批 4=
  39.2+24.8=64MB（贴线——依赖 §4 精估收敛余量）。
- **单 Model 路径零变化**：执行槽语义仅在多 Model 并发时产生等待；单
  Model 持槽无竞争（try→hold 同步完成），行为与现版本逐字节一致（实现
  论证进 B1.2）。
- 等槽上限：等槽批的挂起份额持续占账——若无限制等待会饿死其他提交；
  等槽计入既有等待者/在途上限（不新增第二套上限语义）。

## 4. 执行份额精估（B1.1 取证定稿：范围收缩为两个小项）

取证结论（file:line 证据见 B1.1 取证报告，2026-11-12）：
- **CPU 像素路径 24B/px 无生命周期收敛空间**——合并缓冲（batch.rs:125-136
  作用域至 run_batch 返回）与 ORT 副本（model.rs:419-437）两份 12B/px
  执行窗口真实并存，口径属实不高估。
- **GPU 直传路径无需收敛**——exec=0 已与 host 物理驻留相符（设备侧组装，
  零 CPU 回读）；pending 12B/px 记 device 内存入混合包络（语义混记，
  收敛该账会弱化 device 泄漏拦截，与红线相抵，**维持**）。
- 可收敛项仅一：编码路径源 RGB 3B/px 瞬态面（解码后即弃却按执行窗口计，
  input.rs:246/445-455，高估 ≤6.2MB/项@1080p）——按实驻留收敛。
- 包络语义澄清：budget.rs 包络命名/注释补一句"host/device 混记总账"
  （B1.3 顺手，防后续误读）。
- **错峰后 CPU 批 4 算术自核**：单 Model 执行态 (12.4+39.3)MB + 对侧挂起
  12.4MB = 64.1MB = **61.1MiB < 64MiB（余量 ~3MiB）——不依赖精估收敛
  也在线内**；批 3 更宽裕（29.4+18.6=48MB）。

## 5. 护栏验证矩阵（B1.4/B1.5 测试面）

- 守恒族（批 E 扩展）：双 Model 并发全周期归零；等槽期取消/TTL/排空
  归还；上限整笔拒绝无部分入账；错峰等待期挂起份额不泄漏。
- 真装配：FFI 双 Model e2e（两窗口并发+错峰+各自关闭排空互不干扰）。
- 回归：单 Model 全量既有测试零变化。

## 6. 量化口径（B1.6，MET-2）

- 主目标：双 Model 批 3/4 吞吐（rejected 归零为解锁判据）。
- 保护指标：P99 尾延迟（含错峰等待，对照批 2 基线）；单 Model 吞吐零
  回归；事件日志/内存监控条款（621.14 惯例）。
- 不承诺：repro 层 177（无护栏理想值）；8 路@25fps 满额（评估已定稿
  不可达）。
