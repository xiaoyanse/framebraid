# GPU 帧级联

在 v0.7.0 级联同步与异步入口上增加 NV12 GPU 帧输入，按 ABI 次版本及能力位协商。像素与编码路径保留原合同。二级模型现有攒批配置显式设为 4 时，可按最多四个 ROI 直接写入一个 CUDA 张量。其他配置使用逐 ROI 执行。既有实时队列、取消、回执、跳过项及结果所有权继续适用。

一次映射完成 Y 与 UV 各一次搬运，返回前结束纹理借用。一级及二级使用同一份设备侧快照。既有预处理预算按源平面、一级张量及最多一组二级张量保守准入。原生后端工作区与会话缓存另行测量。没有 CUDA 互操作或设备预算不足时，调用方可用对应 CPU 像素及已装载的 CPU 模型显式重试。已接受的请求不自动重放。

实测以 MET-2 为准。比较同画面、同模型和同 ROI 下的检出及坐标，报告耗时、显存采样口径与准入下限。回归超预算拒绝后可恢复，取消或关闭时资源随实际工作退出归还。
